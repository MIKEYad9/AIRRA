## 📖 Overview

AIRRA Sanctuary is an AI-powered personal growth platform designed to help users:

- Track moods and emotional well-being
- Maintain structured journals
- Analyze personal growth patterns
- Receive AI-generated insights and recommendations
- Build healthier habits
- Monitor energy levels and productivity
- Create a private digital sanctuary for self-reflection

Rather than functioning as a simple diary, AIRRA acts as an intelligent companion that helps users understand themselves better over time.

## 🛠️ Local Development

### Prerequisites

- Node.js 18+
- npm
- Google Gemini API Key

### Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/airra-sanctuary.git
```

Move into the project directory:

```bash
cd airra-sanctuary
```

Install dependencies:

```bash
npm install
```

Create an environment file:

```bash
.env.local
```

Add your Gemini API key:

```env
GEMINI_API_KEY=your_api_key_here
```

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:5173
```
